# ejercicio-coleccion
Este programa resuelve un problema de la vida real aplicando colecciones de datos en Python. Se utiliza la estructura de datos conjunto (set) para almacenar y organizar una lista de frutas, aprovechando su propiedad nativa de no permitir elementos duplicados.
Funcionalidades principales:

# Agregar frutas: 
Permite registrar frutas asegurando que no se repita ninguna.

# Mostrar frutas: 
Recorre y muestra en pantalla de forma ordenada todas las frutas guardadas.

# Buscar fruta: 
Verifica si una fruta específica ya existe en la colección.

# Eliminar fruta: 
Permite quitar una fruta de la lista.
